# Промпт для Gemini — портреты мастеров

Прогонять **по одному человеку за раз** (иначе модель смешает лица).
Итог: вертикальный портрет 3:4 → `public/team/<имя-фамилия>.jpg`,
затем прописать имя файла в `photo:` в массиве `TEAM` в `src/content.ts`.
Сейчас там лежат готовые портреты Дениса, Ильи и Антона.

## Промпт

```
Отредактируй фото, сохранив лицо человека абсолютно неизменным: те же черты, форма носа, глаз, губ, скулы, овал лица, причёска, растительность на лице, возраст, морщины и родинки. Не омолаживай и не «улучшай» лицо — это должен быть узнаваемо тот же человек. Замени только одежду, фон и свет. Одежда: тёмно-зелёная изумрудная (#1F5C3A) рабочая куртка-софтшелл премиального кроя — стоячий воротник, плоская центральная молния, аккуратные нагрудные карманы; под ней чёрная техническая футболка. На левой стороне груди тонкая латунно-золотая (#C8A96A) вышитая монограмма «ЦГ» размером со спичечный коробок, без брендов и надписей. Ткань новая, отглаженная, матовая, сидит по фигуре. Никаких строительных жилетов и светоотражающих полос. Фон: однотонный тёмный градиент, почти чёрный с холодным зеленоватым подтоном (#0A0F0C → #14211A), плавно светлеющий за головой, без единого объекта. Свет: драматичный студийный по схеме Рембрандта — большой софтбокс слева сверху под 45° даёт мягкую скульптурную тень на щеке, контровой свет справа сзади с тёплым латунным оттенком (#C8A96A) очерчивает контур плеча и волос тонкой золотой линией, заполняющий минимальный, тени глубокие, низкий ключ. Кадр: портрет по грудь, лицо в верхней трети, взгляд прямо в объектив, выражение спокойное и уверенное, голова на три четверти, снято как на 85mm f/1.8 — резкое лицо, мягкое размытие фона. Обработка: кинематографический цветокор, изумрудные тени и латунные света, кожа с сохранённой текстурой без пластикового сглаживания, лёгкое плёночное зерно, контраст выше среднего. Формат: вертикальный портрет 3:4. Без текста, водяных знаков, логотипов, инструментов, каски, перчаток и очков. Только фотореализм.
```

## Если лицо поплыло

```
Лицо изменилось. Верни его точно как на исходном фото, меняй только одежду, фон и свет.
```

## Развести три портрета между собой

Добавить в конец основного промпта одну строку:

- **Мастер I** — `свет слева, голова влево, выражение серьёзное`
- **Мастер II** — `свет справа, голова вправо, подбородок приподнят, полуулыбка`
- **Мастер III** — `свет спереди сверху, голова прямо, взгляд чуть в сторону`
